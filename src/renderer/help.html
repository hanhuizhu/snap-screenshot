用法

  1. 按 ⌃⌘A，屏幕变暗，鼠标处出现放大镜（带坐标与取色）。
  2. 移动鼠标，光标下的窗口/控件会自动高亮，点击即可选中；也可以按住拖拽自由框选。
  3. 选区确定后拖动 8 个控制点微调，方向键 1px 微调（按住 Shift 为 10px）。
  4. 用工具栏的矩形 / 椭圆 / 箭头 / 画笔 / 马赛克 / 文字做标注，再复制、保存或钉在屏幕上。
